Let's brainstorm "$ARGUMENTS" together, and keep what comes out of it in Datablush.

1. Call discuss with this topic first: it starts the discussion, or picks it up with everything decided, dropped and left open so far.
2. Then think it through with me as usual: ask questions, compare options, push back.
3. As things settle, save them with update_discussion: each decision with why, ideas we drop with why, context worth keeping, and questions only someone else can answer (with why it matters, the options and your recommendation; never pick who should answer). Save outcomes, not the chit-chat.
4. When it feels decided, ask me: "Turn this into tasks?" If yes, propose the tasks, each with a plan (a short summary, what will change, how we'll know it's done), and create them with create_tasks: decision "approve" if I approve the plans, "review" if the team should review them.
